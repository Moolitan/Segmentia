# web_artifact_with_theme

## Goal
A 5-turn artifact-building task that first creates a landing page, then applies a coherent visual theme.

## Expected behavior
- Read the event brief
- Build a structured landing page artifact
- Add more sections over turns
- Apply a consistent theme and improve hierarchy

## Context mode
seed_files

## Primary output
event_landing_page

## Notes
If available, `web-artifacts-builder` and `theme-factory` capabilities in your environment may serve as useful reference points as you iteratively build and style the page across turns.
