# mcp_server_and_spec

## Goal
A 5-turn task that plans an MCP server and then produces a short supporting spec.

## Expected behavior
- Read the issue API brief
- Plan tool surface and parameters
- Sketch minimal project structure
- Write a short spec
- Review the plan for likely real-world agent pitfalls

## Context mode
seed_files

## Primary output
mcp_server_spec.md

## Notes
If `mcp-builder` tooling is available in your environment, it may offer a useful starting point for server structure and tool surface design. For the written spec, `doc-coauthoring` conventions can help ensure clarity and completeness — refer to either as needed.
