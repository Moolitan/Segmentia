# launch_poster_page_pack

## Goal
An 8-turn multi-artifact launch pack task: create a static poster, build a simple page, and unify them under one theme.

## Expected behavior
- Read the open day brief
- Create a poster concept/output
- Build a short web page
- Unify poster and page visually
- Check consistency at the end

## Context mode
seed_files

## Primary outputs
- open_day_poster
- open_day_page

## Variant
This is the explicit-skill version of the benchmark prompts. Each turn directly instructs the agent to reference and use the relevant skill(s).
