# baseline_feature_brainstorm

## Goal
A 5-turn near-miss baseline task. The agent discusses a possible feature for an existing tool,
but should not need to invoke a formal writing/document skill.

## Expected behavior
- Read the provided product context
- Discuss feature value, tradeoffs, and edge cases
- Stay in plain text discussion mode
- Avoid turning the task into a proposal/spec/design doc

## Context mode
seed_files

## Primary output
Plain text discussion only
