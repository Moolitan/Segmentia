# SegKV 研究笔记 · 导读(从这里开始)

本文件夹是 **SegKV** 的研究记录:在 agent 工作负载中,把反复出现的固定文本段
("skill")的 KV 缓存跨请求复用,以消除重复 prefill 开销,同时保住生成质量。
四篇笔记按顺序构成完整的表征(characterization)阶段,**建议从笔记一顺序读到
笔记四**——每篇接续前一篇的结论提出下一个问题。每篇开头均有导读与摘要,术语在
第一次出现处给出直观解释,不需要先验知识。

## 一句话主线

> 跨上下文复用一段 skill 的 KV,误差精确分解为位置与内容两半:**位置半边**由
> 免训练重旋转精确修复;**内容半边**表现为深层 V 漂移(相似度 ~0.5),且
> **宽(全 token)× 深(深层)**,token 级选择性重算失效、层级续算可修但节省
> 有限。然而把位置修好后直接测**真实输出**:**单次复用在产物层面大体无损**
> (24 点中 14 点几乎一致),少数分叉点也只是 agent 选了同样合理的另一条下一步
> 动作——**端到端可行性成立**。研究自此收敛到设计阶段:为本场景构建免训练、
> 按深度的 **V 修复(跨注意力恢复)机制**(笔记四 §6)。

## 两类实验,勿混淆

- **笔记一至三**测模型**内部**的 K/V/激活相似度(复用后内部表示偏了多少);
- **笔记四、五**测模型**实际输出/产物**的变化(最终裁决性的量)。

## 当前进展与下一步

- **已确立**:(1) 位置误差免训练精确修复(重旋转;笔记四独立校验:第 0 层 K
  恢复 1.000,深层 K 0.83–0.91)。(2) 内容误差宽且深:深层 V ~0.5,97% token
  漂移,恢复曲线无拐点(笔记一、三)。(3) 修复机制:残差流检查点+深层续算,
  14B 真实大漂移下浅检查点回收 86%(笔记二)。(4) 端到端可行性:位置修复后
  直接复用,14/24 产物近无损,6/24 分叉均为合理替代动作,由决策分叉度决定
  (笔记四)。(5) 修复的输出端边界:能救回掉分中等的点、救不回最狠的点;
  修更深无增益,要修就固定最浅档 resume@4(笔记五)。
- **下一步**:在同样 24 个复用点上实现 CacheBlend(重算 18% token)、EPIC
  (边界 token)作基线,与不修 / resume@4 放进同一张"产物质量 vs 计算开销"图
  (对标 CacheSlide Fig.10 的对比形式)。
- **留作系统级评估**:闭环 rollout(真实 agent 回路,复用 ON/OFF 跑完任务 +
  任务级 LLM-judge),在系统原型完成后整体执行,不阻塞机制设计。

## 竞品工作

最接近的工作是 **CacheSlide(FAST'26,`fast26-liu-yang.pdf`)**:同样面向 agent
场景的跨位置 KV 复用。其修复路线为 CCPE(CoPE + 按任务 LoRA 续训的位置编码)+
Weighted Correction Attention(第 1 层按 K 偏差选 top-26% token,逐层加权融合,
CKSim 阈值 0.12);更早的 CacheBlend 重算 ~18% token,EPIC 重算每块边界 64
token。三者共同前提"漂移集中于少数 token"在本场景被笔记三否定;CacheSlide 并
非免训练。SegKV 的差异化路线:免训练重旋转 + 按深度的跨注意力修复。
