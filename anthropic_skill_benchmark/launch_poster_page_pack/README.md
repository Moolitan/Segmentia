# launch_poster_page_pack

## Goal
A 5-turn multi-artifact launch pack task: create a static poster, build a simple page, and unify them under one theme.

## Expected behavior
- Read the open day brief
- Create a poster concept/output
- Build a short web page
- Unify poster and page visually
- Check consistency at the end

## Context mode
seed_files

## Primary outputs
- open_day_poster
- open_day_page

## Notes
Your environment may include capabilities like `canvas-design` for visual composition, `web-artifacts-builder` for page construction, and `theme-factory` for cross-artifact visual unification — refer to whichever feel relevant at each stage of the task.
