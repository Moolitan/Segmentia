# internal_comms_incident_update

## Goal
An 8-turn internal communications task centered on an internal service incident update.

## Expected behavior
- Read the factual incident notes
- Produce a calm internal update
- Tailor the message for leadership readability
- Add FAQ and final broadcast-ready text

## Context mode
seed_files

## Primary output
incident_update.md

## Variant
This is the explicit-skill version of the benchmark prompts. Each turn directly instructs the agent to reference and use the relevant skill(s).
