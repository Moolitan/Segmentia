# baseline_update_polish

## Goal
A 5-turn near-miss baseline task. The agent polishes a project update into clearer team-facing text,
but should not need to invoke a formal internal communications skill.

## Expected behavior
- Read the raw project update
- Rewrite it for clarity and casual team sharing
- Keep the result concise and understandable
- Avoid turning it into a formal report or incident update

## Context mode
seed_files

## Primary output
A polished plain-text team update
