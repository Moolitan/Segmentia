This week we mainly worked on running a multi-turn agent benchmark and have already connected several tasks into one unified script. We have some early results now, but they are not very stable. Some tasks finish successfully, while others fail halfway through, and even repeating the same configuration can lead to different outcomes. We suspect this may be related to skill injection and the later tool execution path, because once the conversation history gets longer, the behavior in later turns seems to drift more easily. Next we plan to add more logging to check whether prompt tokens, prefix cache, and tool call counts are related.
