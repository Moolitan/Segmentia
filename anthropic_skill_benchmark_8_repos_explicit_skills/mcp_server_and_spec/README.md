# mcp_server_and_spec

## Goal
An 8-turn task that plans an MCP server and then produces a short supporting spec.

## Expected behavior
- Read the issue API brief
- Plan tool surface and parameters
- Sketch minimal project structure
- Write a short spec
- Review the plan for likely real-world agent pitfalls

## Context mode
seed_files

## Primary output
mcp_server_spec.md

## Variant
This is the explicit-skill version of the benchmark prompts. Each turn directly instructs the agent to reference and use the relevant skill(s).
