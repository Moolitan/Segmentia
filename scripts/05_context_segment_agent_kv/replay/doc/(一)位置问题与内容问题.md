# SegKV 研究笔记(一):跨上下文复用 KV 缓存的误差分解——位置误差与内容误差

## 导读

本笔记是 SegKV 系列研究记录的第一篇,从零讲起,不假设读者具备 KV 缓存复用的先验
知识;所有术语在第一次出现处给出直观解释。系列的总目标:在 agent 工作负载中,把
反复出现的固定文本段("skill")的 KV 缓存跨请求复用,以消除重复 prefill 开销,
同时保住生成质量。

**摘要.** 跨上下文复用一段 KV 缓存,相对于在新上下文中完整重算,其误差可被精确
分解为两个独立来源:**位置误差**(该段落在序列中的绝对位置改变)与**内容误差**
(该段前文内容改变)。本笔记的三个结论:(1) 位置误差可由免训练的 RoPE 重旋转
**精确**修复,且在本工作负载的位置范围内无外推风险;(2) 内容误差集中在深层,且
**V 的漂移远大于 K**(深层 K 余弦相似度 0.8–0.9,V 仅 ~0.5),其机理是 K 含有大
幅值、跨上下文稳定的离群维度,而 V 的能量均匀分布且整体随前文变化——该观测与
CacheSlide(FAST'26)"V 相似度紧随 K"的论断在深层相反;(3) 由于 K、V 同源于
同一残差流激活,"只重算 V"不构成有效的节省路径,修复必须从"减少需要重算的
残差流激活"入手。

---

## 1. 背景与问题设定

现代 LLM agent 在多轮任务中反复加载固定的"技能说明书"(skill):一段指导模型完成
特定子任务的长文本,例如 `internal-comms` skill 描述事故通报的写作规范。在一次
多轮对话中,同一 skill 文本会**逐字重复出现多次**——我们把第 k 次出现记作
occurrence k,简写 **occ_k**。

每次出现,模型都要对这段完全相同的文本重新执行 prefill。SegKV 的目标是:对 skill
段**算一次、缓存其 KV、后续出现时直接注入**,消除重复计算。核心问题随之而来:
注入的 KV 是在旧上下文中计算的,与"在新上下文中老实重算"的结果存在偏差。本笔记
回答:**这个偏差从哪里来,各部分有多大,哪部分可以被廉价修复。**

---

## 2. 预备知识

后文的分析全部建立在以下机制之上,逐项给出最小必要的说明。

**Token.** 模型以 token(词或子词单元)为最小处理单位;一段 skill 文本对应数百
到数千个 token。

**层与残差流激活 h_l.** Transformer 由一摞层组成(本工作主力模型 Qwen3-14B 为
40 层),数据自第 0 层流向最深层。token t 在第 l 层的中间表示是一个向量,记作
`h_l`,称为**残差流激活**(residual-stream activation):它编码"模型读到第 l 层
时对该 token 的当前理解"。一个直观例子:句子"我坐在河边的**岸**"中,"岸"在
第 0 层的 `h_0` 只含字面义(河岸/堤岸混杂);随层数加深,模型通过注意力吸收前文
"河边",深层 `h_l` 才确定为"水边的陆地"。由此得到贯穿全文的关键事实:

> **同一段文本,置于不同前文之后,其深层激活 `h_l` 不同。**

**注意力.** 每个 token 通过注意力机制读取其前方所有 token 的信息,这是前文影响
`h_l` 的唯一通道。

**K 与 V.** 在每一层,模型从 `h_l` 经两个线性变换分别得到 **K**(Key,供其他
token 检索的"索引")和 **V**(Value,被检索命中后实际传出的"内容")。注意:
**K 和 V 同源于同一个 `h_l`**——`h_l` 变,二者皆变。该事实在 §6 决定了修复方案
的结构。

**KV 缓存.** 推理时模型把已算出的各层 K、V 存入 KV 缓存,后续 token 的注意力直接
读取。SegKV 复用的正是 skill 段的这份缓存;误差即"注入的 K/V"与"新上下文中重算
的 K/V"之差。

**RoPE 与位置.** 模型用 RoPE(旋转位置编码)表达 token 的位置:按位置索引对 K
施加一个确定的旋转。**位置信息只作用于 K,V 不携带位置。**

**度量.** 全文用**余弦相似度**衡量"复用的 K(或 V)"与"重算真值"的接近程度:
1.0 表示无损,数值越低偏差越大。

---

## 3. 误差分解

skill 段在 occ_k 被复用时,相对 occ1 缓存生成时刻,有且仅有两个变量发生改变:

- **位置误差**:skill 段的绝对起始位置后移(对话变长);
- **内容误差**:skill 段的前文内容不同(occ1 前是一段对话,occ_k 前是另一段)。

二者性质完全不同:位置误差由 RoPE 的确定性结构产生,内容误差由注意力对不同前文的
聚合产生。§4 与 §5 分别处理。

---

## 4. 位置误差:免训练重旋转,精确修复

### 4.1 方法

由 §2,位置仅通过对 K 的旋转表达。缓存的 K 携带 occ1 位置的旋转;复用到 occ_k 时,
将其按位置差 `delta = occ_k 起点 − occ1 起点` **重旋转**(re-rotation)到新位置
即可。该操作只作用于 K,不触碰 V(实现见 vLLM 侧 `context_segment_cache/rope.py`)。

### 4.2 正确性

可证明:只要 skill 段的残差流激活 `h_l` 不变,对缓存 K 重旋转后得到的结果,
**逐层精确等于**"该段在新位置直接计算所得的 K"。即:

> **位置误差可被免训练地、精确地修复。**

### 4.3 边界条件

重旋转唯一的失效区是新位置超出模型预训练见过的最大长度(RoPE 外推区)。实测本
工作负载:Qwen3-14B 预训练最大长度 40960,trace 中 skill 复用的最深位置为
24666(约上限的 60%),全程处于安全区内。

### 4.4 消融证据

数据中含一组"不做重旋转"的对照(8 个案例平均):

| 配置 | K 相似度 | V 相似度 |
|---|---|---|
| 重旋转 | 0.900 | 0.743 |
| 无重旋转 | 0.636 | 0.743 |

两个读数:(1) 重旋转把 K 从 0.636 提升至 0.900——这正是被修复的位置分量;
(2) V 在两种配置下几乎逐位相同(0.7432 vs 0.7433),证实重旋转与 V 正交。
这张表同时确立两个事实:**位置分量可由旋转完全回收;V 的全部偏差与位置无关,
纯属内容误差。**

## 5. 内容误差:深层 V 漂移

### 5.1 成因与逐层放大

skill 文本逐字不变,但前文不同,故 skill 内每个 token 经注意力聚合到的前文信息
不同,`h_l` 随之偏移,K、V 随之偏移。且该偏移**逐层放大**:第 0 层 token 尚未
读取前文(相似度恒为 1.0),每深一层多吸收一次"对不同前文的注意力",误差逐层
累积,**最深层偏差最大**。

### 5.2 逐层测量:V 远坏于 K

对每层 K、V 直接测量相似度(`kv_drift_analysis.py`),在两个规模差异极大的案例
(skill 长度 71 与 3313 token)上结论一致。代表性层:

| 层 | K 相似度 | V 相似度 |
|---|---|---|
| 0 | 1.000 | 1.000 |
| 15 | 0.928 | 0.776 |
| 20 | 0.826 | 0.489 |
| 39(最深) | 0.908 | 0.515 |

深层 K 维持 0.8–0.9,而 **V 跌至 ~0.5**(向量夹角接近 90°,实质不可用)。

### 5.3 K/V 不对称的机理

检视 K、V 的内部构成,可定位一个明确的物理原因:

- **K 含有大幅值且跨前文稳定的离群维度**(实测单一维度即可占据 K 能量的大半)。
  这些维度把 K 的余弦相似度"锚住"。
- **V 无此类离群维度**:能量均匀分布,且各维均随前文变化,前文一变 V 整体偏移。

概括为本系列最核心的观测:

> **K 近似"索引":其身份跨前文稳定,可复用。**
> **V 近似"按前文加工的内容":前文变则内容变,不可直接复用。**

### 5.4 与相关工作的关系

CacheSlide(FAST'26)在其 §3.2.1 中以 CKSim 度量 PMKD,并声明"V 矩阵的相似度
紧随 K 矩阵"。我们的逐层数据显示:该论断仅在浅层成立;**深层 K、V 严重分家
(K ~0.9,V ~0.5)**,且在两个量级悬殊的案例上均复现。这一分歧并非矛盾,而是
场景差异所致:CacheSlide 的 RPDC 场景中复用段间相对顺序保持、前文变化有限;
本场景是**整段 skill 被搬入一段完全不同的对话**,内容误差被充分激发。深层 V 漂移
因此是本场景特有的、必须正面处理的问题。

## 6. 修复的结构性约束与初步验证

### 6.1 约束:"只重算 V"不省计算

既然坏的是 V,最直接的设想是只重算 V。但 §2 已给出:K、V 同源于同一 `h_l`——

- 正确的 V 依赖正确的 `h_l`;
- 而获得正确的 `h_l` 必须执行该层完整的注意力计算(开销主体);
- `h_l` 既得,顺带计算 K 的代价可忽略。

故"只重算 V、保留 K"不构成节省。**有效的节省只能来自减少需要重算的 `h_l`**,
即减少层数或减少 token 数。

### 6.2 初步验证:残差流检查点 + 深层续算

按层数节省的具体方案:缓存时除 K/V 外,**额外保存 skill 段在中间层 N 输入处的
残差流激活 `h_N`(检查点)**;复用时跳过前 N 层,自检查点续算,并令深层注意力
可见真实新前文。风险在于:检查点 `h_N` 携带旧前文的影子,深层续算能否将其拉回
真值需实验回答。

在 Qwen3-1.7B(28 层)上构造 `P1 + skill` 与 `P2 + skill` 两种前文,比较三条
路径(完整重算 truth / 直接复用 reuse / 自第 N 层续算 resume@N)的深层 V 相似度
(`residual_checkpoint_probe.py`):

| 配置 | 跳过层比例 | 末层 V 相似度 | 缺口回收率 |
|---|---|---|---|
| 直接复用 | 0% | 0.912 | — |
| resume@2 | 7% | 0.998 | 96% |
| resume@6 | 21% | 0.991 | 79% |
| resume@8 | 29% | 0.982 | 67% |
| resume@12 | 43% | 0.968 | 43% |

(缺口回收率 = 在"直接复用 → 完整重算"区间内补回的比例。)

机制成立:深层续算确实能借助真实前文把 V 拉回;检查点越浅,回收越完整。但该
预实验的基线漂移较小(0.912,而非 14B 实测的 ~0.5),且为公平对比未实际跳过
浅层计算。**在 14B 真实大漂移场景下的完整验证、以及由此引出的"按层 × 按 token"
联合选择问题,分别见笔记二与笔记三。**

---

## 7. 结论

1. **位置误差已解决**:免训练 RoPE 重旋转精确修复,工作负载位置范围内无外推
   风险;位置不是瓶颈。
2. **内容误差是核心问题**:源于深层注意力聚合不同前文;**V 远坏于 K**(深层
   ~0.5 vs 0.8–0.9),机理为 K 的稳定离群维度与 V 的均匀敏感分布。该观测与
   CacheSlide 的"V 紧随 K"论断在深层相反,是本场景的特有特征。
3. **修复的结构约束**:K/V 同源于 `h_l`,只重算 V 不省计算;有效路径是减少重算
   的 `h_l`。残差流检查点 + 深层续算的机制已在小模型上验证成立,完整评估见
   笔记二。
