# SegKV 研究笔记 · 导读(从这里开始)

这个文件夹是 **SegKV**(把 agent 反复用到的 "skill" 的 KV 缓存下来复用、以省时间)的
研究记录。下面五篇按顺序排好,**建议从笔记一顺着读到笔记五**——每一篇都接着上一篇的结论
往下问下一个问题。每篇开头都有"这份文档怎么读 + 一句话结论",名词第一次出现都用大白话
解释,不需要先验知识。

## 一句话主线

> 复用一段 skill 的 KV,**位置那一半误差**用免训练的旋转就解决了;真正的难点是**内容那
> 一半**——深层的 V 会漂、又宽又深,内部看坏得厉害(V 相似度只剩 0.5)。但把位置修好后
> 去测**真实输出**会发现:**单次复用产物大体无损**(24 个点里 14 个几乎一模一样),少数点
> 只是让 agent **换了个同样合理的下一步动作**,不是文字坏掉。**但误差会累积**——补做的累积
> 实验显示一次上游复用就在下一次额外加 30–130% 偏移、不自愈。所以"复用越多偏得越多"是真实
> 风险,而"到底伤不伤最终产物"还需**闭环 rollout + 任务级质量裁判**定论(见笔记四第 4 节)。

## 两类实验,别混淆

- **笔记一~三、五**测的是**模型内部**的 KV/激活相似度(skill 复用后内部变了多少)。
- **笔记四**测的是**模型写出来的输出/产物**变了多少(这才是最终要紧的)。

## 当前进度与下一步

- **已确立**:DP1(免训练 re-rotation 解决位置;笔记四已独立验证:第 0 层 K 重旋转后回到
  1.000,深层 K 0.83–0.91)。修 V 的机制(按层深+中间存档,按 token 受邻居污染封顶)在
  笔记二三五里测清楚了,但**是否真的需要修,取决于输出层面的结论**。
- **已发现**:笔记四——位置修好后**单次**复用产物大体无损,少数复用只是改变 agent 的下一步
  动作(决策分叉);但补做的累积实验(4.1)证明**误差会累积、不自愈**(一次上游复用加
  30–130% 偏移),所以"复用越多偏得越多"是真实风险。
- **下一步**:**闭环 rollout**(笔记四 4.2)——用 `real_system/` 真 agent harness,复用 ON vs OFF
  各自把任务跑到底,用任务级 LLM-judge 比**最终产物**是否真变差。这一步决定:(a) 是否需要
  "修 V"或"周期性刷新缓存";(b) 触发信号落在"累积速率 + 决策分叉度"上(而非曾经设想的任务
  核心度)。在此之前不写最终设计纲领(原笔记六已退役)。
